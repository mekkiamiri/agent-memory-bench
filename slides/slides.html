~ 3                                   ← 3 tours de bavardage

SessionAdvisors : org.springframework.ai:spring-ai-session-advisor

{{CHROME}}
SessionAdvisors est dans org.springframework.ai:spring-ai-session-advisor (2.1.0-RC2), paquet org.springframework.ai.session.advisor ; build() renvoie la liste des advisors. Le billet : chaque dépréciation nomme son remplaçant. Pas de session par défaut, volontairement : une session partagée mélangerait les historiques. Dépôts JDBC : JdbcSessionRepository (PostgreSQL, MySQL, MariaDB, H2).
